# FilingFigures results viewer

Every test filing's six figures: the XBRL answer key next to each model's answer, with errors labelled. Built from the one test run's saved predictions with `figures space`.

Code and write-up: [github.com/nathankyryk/filing-figures](https://github.com/nathankyryk/filing-figures)
